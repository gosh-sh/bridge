# Groth16 Wrapper for Halo2 Verifier

## Overview

This directory contains a complete implementation of a Groth16 wrapper for Halo2/PLONK/SHPLONK proofs, enabling deployment of the verifier on Ethereum mainnet within the 24KB contract size limit.

## Problem

The Halo2 verifier contract generated by snark-verifier is 28.8KB, exceeding Ethereum's 24KB limit (EIP-170).

## Solution

Wrap the Halo2 proof verification in a Groth16 circuit, which produces a tiny verifier (~1-2KB).

**Architecture:**
```
Halo2 Proof (8224 bytes)
    ↓
Groth16 Circuit (verifies Halo2 proof)
    ↓
Groth16 Proof (~300 bytes)
    ↓
Groth16 Verifier Contract (~1-2KB) ✓ Fits in 24KB!
```

## Implementation Status

**✅ COMPLETE** - All core modules implemented and compiling

### Modules Implemented

1. **Fiat-Shamir Transcript** (`transcript.go`)
   - Keccak256 hashing
   - Challenge derivation (β, γ, α, ζ, μ, γ_kzg, z')
   - Matches snark-verifier's EvmTranscript

2. **KZG Verification** (`kzg.go`)
   - KZG commitment opening verification
   - SHPLONK multi-opening verification
   - Pairing checks using gnark's BN254 gadgets

3. **PLONK Verification** (`plonk.go`)
   - Gate constraint verification
   - Permutation argument verification
   - Public input binding
   - Quotient polynomial verification

4. **Main Circuit** (`circuit.go`)
   - Integrates all modules
   - Defines witness structure
   - Implements full verification flow

5. **Proof Parser** (`proof_parser.go`)
   - Parses 8224-byte Halo2 proof
   - Extracts commitments, evaluations, SHPLONK proof

## Usage

### 1. Export Halo2 Proof

```bash
cargo run --example export_proof_for_gnark -- \
    --input data/deposit_proof_42.snark \
    --output gnark-wrapper/halo2_proof.json
```

### 2. Generate Groth16 Proof

```bash
cd gnark-wrapper
go run .
```

This will:
- Load the Halo2 proof
- Compile the Groth16 circuit
- Generate proving/verification keys
- Generate a Groth16 proof
- Export Solidity verifier to `Groth16Verifier.sol`

### 3. Deploy Verifier

```bash
# Deploy the generated Groth16Verifier.sol
forge create Groth16Verifier --rpc-url $RPC_URL --private-key $PRIVATE_KEY
```

## Technical Details

### Proof Structure

The Halo2 proof is 8224 bytes:
- 50 witness commitments (3200 bytes)
- 3 quotient commitments (192 bytes)
- 147 evaluations (4704 bytes)
- 2 SHPLONK opening proofs (128 bytes)

### Verification Algorithm

1. **Derive Challenges** (Fiat-Shamir)
   - Absorb public inputs
   - Absorb witness commitments → squeeze β, γ
   - Absorb quotient commitments → squeeze α, ζ
   - Absorb evaluations → squeeze μ, γ_kzg, z'

2. **Verify PLONK Constraints**
   - Gate constraints: `q_L·a + q_R·b + q_O·c + q_M·a·b + q_C = 0`
   - Permutation: `Z(ωζ)·∏(a+β·σ+γ) = Z(ζ)·∏(a+β·ζ·ω^i+γ)`
   - Public inputs: `L_0(ζ)·(a(ζ) - PI) = 0`

3. **Verify SHPLONK Multi-Opening**
   - Compute batched commitment F
   - Verify: `e(F, [1]₂) = e(W', [x]₂ - [z']₂)`

### Dependencies

- **gnark** v0.14.0 - ZK-SNARK library
- **gnark-crypto** v0.19.2 - Cryptographic primitives
- **Go** 1.22+ - Programming language

## Challenges

### Circuit Size

**Challenge:** Full SHPLONK verification may exceed 24KB limit

**Solutions:**
1. **Optimization** - Reduce constraints, use lookup tables
2. **Circuit Splitting** - Multiple contracts with DELEGATECALL
3. **L2 Deployment** - Deploy on Arbitrum/Optimism (no 24KB limit)
4. **Simplified Verification** - Verify hash of proof instead

**Current Approach:** Implement full verification, then optimize

### Complexity

**Challenge:** SHPLONK is complex and not implemented in gnark

**Solution:** Custom implementation based on:
- SHPLONK paper (https://eprint.iacr.org/2020/081)
- snark-verifier's Rust implementation
- gnark's pairing gadgets
